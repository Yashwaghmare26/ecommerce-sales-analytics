# 🛒 E-Commerce Sales Analytics

## 📌 Project Overview

This project analyzes an e-commerce sales dataset containing 5,000 transactions.

The objective is to analyze sales performance, customer behavior, product performance, regional trends, discounts, delivery performance, payment methods, and customer ratings.

The project follows an end-to-end data analytics workflow using SQL, Python, and Power BI.

## 📊 Dataset

The dataset contains 5,000 e-commerce transactions with information related to:

- Order ID
- Order Date
- Customer ID
- Product Category
- Region
- Quantity
- Unit Price
- Discount
- Payment Method
- Delivery Days
- Customer Rating
- Revenue

The dataset was obtained from Kaggle.
